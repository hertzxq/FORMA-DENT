# FORMA DENT — дизайн-система

Источник: согласованная спецификация и рекомендации ui-ux-pro-max, проверенные 18.10.2026. Автоматически предложенные cyan/neumorphism и liquid-glass не приняты: они расходятся с заданным пользователем направлением. Ниже — осознанная адаптация, а не неизменённая выдача базы навыка.

## Цвета

- Фон: `#F7F5F0`, поверхность: `#FFFFFF`, песочная поверхность: `#EEE9E0`.
- Основной текст: `#252D29`, вторичный: `#59645D`.
- Основная кнопка: `#3C584A`, текст кнопки: `#FFFFFF`.
- Шалфейная поверхность: `#E3EADF`, текст: `#314538`.
- Разделитель: `#D8DDD4`, ошибка: `#A52A2A`, фокус: `#3C584A`.
- Статусы обозначаются текстом и иконкой, а не только цветом.
- Контраст проверяется перед сдачей: обычный текст ≥ 4.5:1, крупный текст и границы значимых элементов ≥ 3:1.

## Типографика и композиция

Основной шрифт — Manrope с кириллицей и системным sans-serif fallback. Заголовки используют ту же гарнитуру, выразительный размер и умеренную плотность; минимальный основной текст 16 px, line-height 1.5. Шрифт при реализации хранится локально, если доступен для загрузки; fallback не блокирует работу сайта.

Контейнер до 1280 px; поля 20 px на мобильном и 40–64 px на широком экране. Hero — асимметричные текст и фотография, ниже компактные факты. Секции имеют 72–112 px вертикального пространства, на мобильном 48–64 px. Карточки — скругление 20–28 px, поля и кнопки 12–16 px. Тонкие границы, мягкие тени только для отделения уровней.

## Взаимодействия

- Размер интерактивной области кнопок не меньше 44×44 px; зубы получают увеличенную область попадания без перекрытия соседей.
- Hover, focus, selected, disabled и error имеют различимые состояния. Фокус — контрастная обводка с отступом.
- Переходы 150–250 ms; Framer Motion только для появления и смены состояния. При reduced motion — без пространственного движения.
- Диалоги через shadcn/ui/Radix: заголовок, описание, trapping focus, Escape, возврат фокуса.
- Range для «До/После» поддерживает клавиши и видимую подпись.
- Формы управляются React state. После неудачной отправки появляется фокусируемый список ошибок со ссылками на поля; у полей — aria-invalid и aria-describedby.
- Валидация не перемещает фокус при каждом blur. Успех объявляется через role=status.
- В мобильном календаре дни и слоты остаются удобными для касания; фиксированная запись учитывает safe-area и нижний отступ страницы.

## Изображения и контент

Крупные светлые интерьеры с натуральными материалами; без ярко-синей медицинской стилистики. Все изображения имеют заданные размеры, подходящее кадрирование и alt; ниже первого экрана — lazy loading. Фотографии врачей и результаты лечения обозначаются как демонстрационные. Не переносить рекламные сообщения с пользовательского референса.

## Проверка

Размеры 375/768/1024/1440 px; отсутствие горизонтального переполнения; клавиатурная запись; диалоги; ошибки форм; reduced motion; читаемость подписей SVG; доступность занятых слотов и поиск без результатов.
