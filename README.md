# FORMA DENT

Русскоязычный демонстрационный frontend современной стоматологии. Создан на React, TypeScript, Vite, Tailwind CSS, Framer Motion, Radix/shadcn-style UI и Lucide React. Дизайн основан на согласованной молочной и шалфейной палитре и рекомендациях ui-ux-pro-max.

## Запуск

Node.js 22.12+ либо современная совместимая версия (при разработке использовалась Node.js 26).

```sh
npm ci
npm run dev
```

Vite выводит фактический адрес в терминале, по умолчанию `http://localhost:5173`. Если порт занят, используется следующий свободный.

```sh
npm test
npm run build
npm run preview -- --port 4173
```

Production-файлы находятся в `dist/`. Для статического хостинга нужен fallback всех маршрутов на `index.html`, чтобы открывался `/demo-schedule`.

## Возможности

- Интерактивная SVG-схема 32 зубов с FDI-нумерацией, поддержкой клавиатуры и подбором лечения по восьми симптомам.
- Поиск услуг, восемь категорий, состав стоимости и переход к подходящему врачу.
- Шесть демонстрационных врачей и два филиала.
- Расписание на 14 дней по Москве: услуги 60/90 минут, шаг 30 минут, занятые интервалы, перерывы и запрет прошлого времени.
- Проверка доступности повторно при подтверждении записи, анонимное восстановление занятости и страница сброса `/demo-schedule`.
- По просьбе пользователя блок налогового вычета снят с главной страницы; его код и регрессионные тесты сохранены в репозитории.
- Диалоги врачей, галерея, сравнение до/после, FAQ, переключение филиалов и демонстрационная форма обратного звонка.
- Мобильная навигация, фиксированная кнопка записи, reduced-motion, доступные подписи и ошибки форм.

## Данные и приватность

Сервер, API-ключи и аналитика для логики приложения не нужны. Все изображения входят в проект. Встроенные Яндекс Карты загружаются из внешнего сервиса; без сети доступен прямой адрес ссылки на карту. Архитектурные изображения и портреты сгенерированы для этого демонстрационного проекта; сравнение улыбки — условные SVG-иллюстрации, а не клинический результат.

В `localStorage` используется только ключ `forma-dent.appointments.v1`. Разрешённые поля записи: `id`, `doctorId`, `branchId`, `serviceId`, `start`, `end`. Имена, телефоны, сведения об оплате и заявление не сохраняются и не отправляются. При недоступном storage запись живёт в памяти до перезагрузки. Повреждённые, неизвестные и пересекающиеся записи не восстанавливаются.

Изменения ключа в другой вкладке обновляют расписание. Это локальная модель: атомарная защита от одновременной записи из нескольких браузеров требует backend. Закрытие диалога заявления очищает введённые сведения.

## Ограничения демонстрации

Сайт не записывает в реальную клинику и не отправляет заявку обратного звонка. Врачи, расписание, цены и пакеты — примеры. Отзывы сняты с главной страницы. Реальные клиники на Яндекс Картах используются как подписанные географические ориентиры, а не филиалы FORMA DENT. Информационный навигатор не ставит диагноз. Заявление не является официальной справкой ФНС; право на вычет и его размер автоматически не рассчитываются.

Для реального запуска необходимо подключить систему клиники, серверную проверку доступности, согласованную политику обработки данных, настоящие контактные сведения и проверенный медицинский/юридический контент.

## Структура

- `src/data/` — каталог, врачи, филиалы, симптомы и FDI-набор.
- `src/lib/` — подбор услуг, интервалы, московские даты, валидация, хранение и тесты.
- `src/features/` — схема зубов, каталог, запись, заявление и блоки клиники.
- `src/components/` — общие блоки и доступные UI-компоненты.
- `src/pages/` — главная страница и демонстрационное расписание.
- `design-system/forma-dent/MASTER.md` — дизайн-система.
- `docs/verification.md` — фактические проверки и ограничения проверки.

Шрифт использует системный sans-serif fallback; внешняя загрузка шрифтов не требуется.
