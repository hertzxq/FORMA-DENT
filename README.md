# FORMA DENT

Адаптивный сайт стоматологии с интерактивной схемой зубов, каталогом услуг и календарём записи. Портфолио-проект на React и TypeScript.

![Главная страница FORMA DENT](docs/screenshots/desktop.png)

## Возможности

- Схема 32 зубов: множественный выбор, FDI-нумерация, управление клавиатурой и рекомендации по симптомам.
- Каталог из восьми услуг с поиском, фильтрами и составом стоимости.
- Шесть реальных специалистов со ссылками на официальные профили их клиник.
- Календарь на 14 дней по московскому времени, длительность услуг 60/90 минут, проверка занятых интервалов и перерывов.
- Галерея, сравнение улыбки до/после, FAQ с плавным раскрытием, карты двух районов Москвы.
- Мобильная версия, доступные диалоги, анимации с учётом `prefers-reduced-motion`.

## Технологии

React 19 · TypeScript · Vite · Tailwind CSS · Framer Motion · Radix UI · Lucide · Vitest · Testing Library.

## Локальный запуск

Нужен Node.js 22.12+; версия для CI указана в `.nvmrc`.

```sh
npm ci
npm run dev
```

Адрес по умолчанию: `http://localhost:5173/`.

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Ключи API и переменные окружения для работы сайта не нужны. Яндекс Карты требуют подключения к интернету.

## GitHub и GitHub Pages

1. Создайте пустой репозиторий на GitHub без дополнительного README.
2. Свяжите локальный проект с ним и отправьте текущую ветку как `main`:

```sh
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin HEAD:main
```

3. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Запустите **Actions → Deploy to GitHub Pages → Run workflow**, выбрав `main`. Последующие push в `main` запускают публикацию автоматически.

Workflow сам получает путь репозитория из настройки Pages. Изображения и внутренние ссылки учитывают этот путь. Отдельный HTML для `/demo-schedule/` создаётся при сборке, поэтому этот адрес открывается и после перезагрузки без серверного SPA fallback.

Для локальной проверки сборки в подкаталоге:

```sh
npm run build -- --base /YOUR_REPOSITORY/
npm run preview -- --base /YOUR_REPOSITORY/
```

Откройте `http://localhost:4173/YOUR_REPOSITORY/`.

Файл `.github/workflows/ci.yml` проверяет тесты и сборку при push и pull request. Публикация описана в `.github/workflows/pages.yml`. Настройка соответствует [документации Vite](https://vite.dev/guide/static-deploy.html#github-pages) и [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Данные и ограничения

Это frontend-прототип: подтверждение сохраняет время в текущем браузере, без отправки заявки в клинику. Реальные профили специалистов приведены с указанием их работодателей; они не представлены сотрудниками FORMA DENT. Цены, расписание и планы лечения служат примерами. Карты показывают реальные клиники как географические ориентиры.

В `localStorage` сохраняются только анонимные поля записи: `id`, `doctorId`, `branchId`, `serviceId`, `start`, `end` под ключом `forma-dent.appointments.v1`. Имя и телефон не сохраняются и не отправляются. Проверка одновременной записи между разными браузерами потребует backend.

Служебная страница `/demo-schedule/` позволяет посмотреть и сбросить локальные записи. Код формы налогового вычета сохранён в `src/features/tax/`, но блок отсутствует на главной странице.

## Изображения и права

Изображения помещений созданы для концепции; сравнение улыбки — условная SVG-иллюстрация. Фотографии реальных врачей взяты с сайтов «Патрики Смайл» и «Чудо Доктор». Источники перечислены в [документе правок](docs/revisions/2026-10-18-browser-feedback-round-3.md).

Фотографии врачей и чужие обозначения не распространяются под лицензией исходного кода. Ссылка на источник не заменяет разрешение на использование: перед публичным размещением этих фотографий нужно получить согласие правообладателей либо заменить их материалами с разрешением на публикацию. Лицензия на свободное использование всего репозитория не назначена.

## Структура

```text
src/components/   Общие блоки и UI
src/features/     Каталог, запись, схема зубов, блоки клиники
src/data/         Данные услуг, специалистов, филиалов и симптомов
src/lib/          Даты, доступность, хранение, валидация и тесты
src/pages/        Главная и служебное расписание
public/           Изображения и favicon
.github/workflows/ Проверки и публикация
```
